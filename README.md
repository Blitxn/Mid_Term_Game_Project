Neko: The long way home

I. Game Overview

   Game Title: Neko: The long way home
   Genre: 3D Platformer
   Unity Version: 6.3 (Editor ver 6000.3.8f1)
   Platoform: Windown (PC)

1.1 Game Objective

    Neko: The long way home is a 3D platform game where players control Neko, a cat, and guide her across a series of floating platforms to reach finish line.
    Along the journey, players must collect items, jump across platforms, avoid obstacles, and prevent Neko from falling into the void. Players must also complete the level before the timer runs out.

1.2 StoryLine

    Neko wakes up on a floating island, far away from her home. Her home is located on the other side of the sky, and the only way to return is by crossing a series of floating platforms.
    Each platform presents new challenges, requiring Neko to run, jump, and carefully navigate the path ahead. Help Neko overcome every obstacle and find her way back home!

1.3 Core Features

    -Player Movement: Control Neko with running and jumping mechanics.
    -Follow Camera: A camera follows the player's movement throughout the game.
    -Floating Platforms: Navigate across static platforms and moving platforms.
    -Collectible: Collect items throughout the level and track the score using the UI.
    -Checkpoint and Respawn: If Neko falls, she respawns at the latest checkpoint.
    -Timer: Complete the level before the countdown reaches zero.
    -Win Screen: Reach the finish line to complete the level.
    -Game UI: Includes a main menu, pause menu, and game over screen.
    
  II. Game Rules
  
     1. Players must guide Neko from the starting point to the finish line.
     2. Players can collect items along the way to increase their score.
     3. Players must avoid falling into the void.
     4. If Neko falls, she will respawn at the latest checkpoint.
     5. Players must complete the level before the timer runs out.
     6. Reaching the finish line successfully completes the level.
     7. If the timer runs out, the game ends.
     
  III. Game Control
  
                Key                   |         Action
                Arrow left            |         Move Left
                Arrow Right           |         Move Right
                Arrow Up              |         Move Forward
                Arrow Down            |         Move Backward
                Space                 |         Jump
                
   IV. Set Up and Play Instruction
   
       1. Set Up
          . Open Unity Hub.
          . Select Add Project from Disk.
          . Select the downloaded project folder.
          . Open the project using the specified Unity version.
          . Wait for Unity to import the assets.
          . Open the main game scene.
          . Press Play to run the game.
       2. How to play
          . Launch the game.
          . Select Play from the main menu.
          . Use the keyboard controls to move and jump.
          . Collect items along the way.
          . Avoid obstacles and falling from platforms.
          . Reach the finish line before time runs out.
